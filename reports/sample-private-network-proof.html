这不是你当前环境的现场实测报告。下面保留历史演示的通用网段与证据结构，不请求任何服务、不重放实时结果。正式验收应在自己的环境运行测试脚本，检查新时间戳和原始 JSON。
示例：委派子网来源
172.20.0.4 / .5

来源必须实际落在该环境的委派子网内。

示例：私有端点目标
172.20.1.4:443

私有 DNS 和直接 TCP 目标应匹配端点 NIC 的真实 IP。

示例：公网上的反向对照
403

还必须检查后端公网关闭、有效身份和数据角色；不能只凭任意 403 下结论。

验收链条

  1. 在 Power Platform 环境内解析正常服务 FQDN，结果为私有端点 IP。
  2. 由委派子网内的诊断容器直接连接该私有 IP 的 TCP 443。
  3. 通过正常域名完成 TLS 握手，检查证书、协议、错误和 CRL 状态。
  4. 确认目标 Public Network Access 为 Disabled，带授权身份的公网请求被拒绝。
